# VowLabs SDK

The VowLabs SDK repository contains small, provider-neutral modules intended
to be consumed by Vow applications and open-source integrations.

## Packages

- `core/` — protocol discovery and shared HTTP capability descriptions.
- `banking/` — provider-neutral bank-account onboarding field schemas.

These modules are deliberately separate from `VowLabs/Offchain`, which hosts
deployable services, workers, and provider integrations.
